## Overview

This project automates the reporting workflow for VIP lounge partnership performance across multiple airports. Three scripts form the pipeline: one builds the input workbook, one collects and audits exchange rates, and one renders the standalone HTML dashboard. The dashboard is a **build artifact** generated by `gerar_relatorio.py` and is not committed to this repository (`*.html` is git-ignored).

> **The data shown in the dashboard is illustrative and does not represent real financial figures or actual partner agreements.**

## Features

| Script | What it does |
|:--|:--|
| `criar_planilha_input.py` | Builds a structured input workbook from the raw partner access base, one sheet per lounge, preserving manually entered fields (paying passengers, currency overrides) across regenerations. |
| `fx_collector.py` | Fetches daily EUR/USD rates from investing.com (European Central Bank as fallback), audits invalid or duplicate dates and text-formatted values that Excel's `AVERAGE` silently ignores, and outputs both the legacy and corrected monthly averages. |
| `gerar_relatorio.py` | Reads the input workbook and renders the standalone HTML dashboard. |

The generated dashboard (`VIP_Lounges_Performance (In).html`) covers:

- Revenue and passenger volume by lounge and partner airline
- Paying passenger percentage
- Published vs. corrected EUR/USD rate comparison, with data quality alerts
- Year-over-year and month-over-month breakdowns
- Responsive layout, print-friendly

## How to use

**Requirements:** Python 3 and `openpyxl`. The exchange-rate collector uses only the standard library (`urllib`), with no external HTTPS dependencies.

```bash
git clone https://github.com/Sena295/Lounge-VIP-Dashboard.git
cd Lounge-VIP-Dashboard
pip install openpyxl
```

Source and output folders come from environment variables, so nothing is hardcoded:

```bash
set VIP_LOUNGE_SOURCE_PATH=C:\path\to\source
set VIP_LOUNGE_OUTPUT_PATH=C:\path\to\output

python criar_planilha_input.py        # 1. build the input workbook
python fx_collector.py 2024-01-01     # 2. collect and audit EUR/USD rates (start date optional)
python gerar_relatorio.py             # 3. generate the dashboard
```

Open the generated `VIP_Lounges_Performance (In).html` directly in any browser: no server or build step required, all data and rendering logic are self-contained in the file.
